# OmniFlow 交互设计手册

版本：2026-10-24。本文是当前交互基线、目标设计与验证计划的统一入口；三种显示模式与核心摘要已实现，其余规划按第 17 节标记。

## 1. 使用方式与决策优先级

### 1.1 状态标记

- **现有**：当前工作区存在对应入口或行为，不等于所有异常与兼容性均已验证。
- **待完善**：已有部分实现，但与目标约定仍有明确差距。
- **占位**：菜单已展示“暂不可用”，原生禁用且没有动作回调。
- **规划**：本手册提出的目标行为，尚未交付；先验证再开发。
- **试验**：存在多个合理方案，需要任务对照，不能视为最终产品承诺。

各节描述目标契约；第 17 节统一记录实现状态和源文件。发生冲突时以用户明确要求和实际代码为准，更新状态，不把文档中的“应当”解释为代码中的“已经”。

### 1.2 基准与边界

优先级：用户明确要求 → 经用户细调的 v1 工作流 → 当前领域计算契约 → 研究证据与设计推断。

- v2 前操作参考历史提交 `ab53eed`，不能把包含 v2 前五阶段的版本当作纯 v1。入口、默认值和快捷键变更前，应对照历史代码与[原技术设计](technical-design.md) §8.2、§8.3、§9.2、§10。
- 数学含义遵守 [v2 技术设计](technical-design-v2-proposal.md)；历史规格用于理解意图，不恢复已淘汰的求解接口或隐式供给。
- 本手册不扩大稳态规划范围：不把连续运行量冒充整数最优建厂方案，不承诺启动动态模拟或短期概率产量保证。
- 已存在的[实现差距](v2-code-gap-assessment.md)、[验证记录](testing.md)用于记录缺口和证据，不替代本手册的交互决策。

## 2. 产品模型与设计依据

### 2.1 用户面对的四层信息

OmniFlow 是可编辑、可求解的工程网络工具。用户主要理解四件事：

| 层次 | 用户问题 | 展示责任 |
|---|---|---|
| 配方与设备 | 什么机器把什么变成什么？ | 配方卡片、编辑器、修饰器 |
| 连接与网络 | 哪些端口实际共享资源？ | 可见连线、全局总线标记、网络查看（规划） |
| 条件与目标 | 从哪里供给、交付多少、受哪些限制？ | 端点内联操作、供应与边界、产线设置 |
| 结果与解释 | 能否达到目标、需要多少设备、为何受限？ | 节点结果、汇总、诊断与定位 |

必须区分：同名资源与同一网络；无线连接与外部供给；用户设定与求解结果；交付与排放；运行量与安装量。可见连线表达端口连接关系，不能把其箭头或标签误解为已经求出的逐边运输流量。

### 2.2 从研究到决策，而非照搬组件

| 依据 | 研究支持的方向 | 本软件采用的判断 | 不能据此声称 |
|---|---|---|---|
| [R1] 认知维度 | 检查修改阻力、隐藏依赖、可见性等权衡 | 高频调量留在节点；共享网络提供追踪；批量动作明确影响范围 | 控件越少越好，或全部设置集中必然更好 |
| [R2] 分层验证模型 | 先验证任务和数据抽象，再验证交互与算法 | 将语义正确、操作可理解、性能足够分开验收 | 构建通过或截图美观即体验正确 |
| [R3] RelEx | 工程网络的主动修改与逻辑/物理关系分析 | 画布、过滤列表、约束编辑围绕同一对象联动 | 必须使用矩阵或照搬四窗口布局 |
| [R4] 心智地图实验 | 所测动态图定向任务受益于布局保持 | 重算不移位；定位可回到原视野；整理由用户触发 | 禁止自动排布，或证明某个固定高度最优 |
| [R5] 图认知负荷 | 规模与密度限制人的图理解能力 | 局部追踪、过滤与概览优先于单纯提高帧率 | 把论文节点数当成产品硬阈值 |
| [R6] 分组表示实验 | 显式组边界有助于所测分组任务 | 先试命名工段框，再单独测试折叠；显示模式另行验证 | 选中即展开或隐藏所有 IO 已被证明有效 |
| [R7] 语义命令架构 | 将用户动作组织为可复用命令与撤销单元 | 菜单、快捷键、右键共用动作；一次批量操作一次撤销 | 必须立即建设复杂的选择性撤销系统 |
| [R8] Whyline | 从结果症状提问并定位原因的调试方式 | 诊断回答“什么未满足、哪些条件相关、在哪里改” | 高亮路径等于求解因果证明 |

上述研究的任务和参与者与本软件不同。采用的是待验证的设计推断，不引用其效果数字作为 OmniFlow 的收益承诺。教材 [B1–B3] 用于持续检查数据表达、认知负担和完整流程。

## 3. 核心任务与操作原则

### 3.1 主流程

创建或打开产线 → 编辑配方与修饰器 → 连接关心的工序 → 明确外供与出口 → 设置目标 → 计算 → 查看结果与限制 → 就地调量或批量修改 → 重算／撤销／保存。

用户不必先画出完整工厂。忽略某个输入的供应链，通过明确外供实现；资源仍被消耗并进入汇总。界面不要求用户理解 Net ID、矩阵列或归一化尺度。

### 3.2 需要持续验证的任务

| 任务 | 用户应能完成的判断或操作 |
|---|---|
| 小型试算 | 少量配方与目标，未画能源来源也能明确设置供给 |
| 调整既有产线 | 直接改目标量或供应上限，理解哪些结果已过期 |
| 规模化编辑 | 批量修改兼容节点，知道哪些被跳过，一次撤销恢复 |
| 追踪关系 | 找到目标、上游来源和共享网络，返回原位置 |
| 诊断失败 | 区分缺来源、供应不足、无出口、无界和服务错误 |
| 方案探索 | 复制、修改、回退，保留配方、边界和环境的一致性 |
| 交付与恢复 | 分清应用设置、保存到本机、导出文件；失败不损坏现有文档 |

### 3.3 不变原则

- 高频数量编辑保持就地操作，完整设置只是补充入口。
- 查看、选择、定位、主题与语言变化不修改计算条件；不自动清空结果。
- 计算只替换数值，不改变节点尺寸、端口位置和手工布局。
- 不用大量常驻说明弥补入口不清；详细内容放进可访问的提示、帮助或文档。
- 操作范围和结果有明确反馈；可逆的日常操作优先依赖撤销，避免反复确认。
- 未实现入口按用户要求可见并禁用；“暂不可用”和“当前未选择对象所以禁用”分开表达。

### 3.4 操作契约速查

下表为目标契约；未统一实现的事务、草稿与保存保护仍按第 17 节列为缺口。

| 操作 | 作用范围／提交 | 撤销与计算影响 | 失败处理 |
|---|---|---|---|
| 改目标量／供应上限 | 当前资源，Enter／有效失焦 | 一次提交一次撤销；结果标过期 | 保留无效草稿并定位字段，不写入错误数值 |
| 保存配方／机器边界 | 当前节点，显式保存 | 整次编辑撤销；涉及语义时结果标过期 | 不部分覆盖旧配置 |
| 切换端点共同模式 | 当前端点的适用资源，明确选择 | 一次撤销，保留独立数量；结果标过期 | 不适用端口禁用并说明 |
| 批量动作（规划） | 明确选区及适用集合，显式提交 | 整批一次撤销；语义变更标过期 | 预检查，禁止静默半成功 |
| 主题／语言 | 本机偏好，即时 | 不进入文档历史，不影响计算 | 不改用户数据 |
| 定位／高亮／搜索（含规划） | 视图或临时状态 | 不进入文档历史，不影响计算 | 保留原图与选择；允许退出临时状态 |
| 拖动／整理／工段布局 | 指定对象，操作结束提交 | 一次布局动作可撤销；不影响求解 | 不改拓扑，无法布局时保留原位置 |
| 应用字典／单位环境 | 当前文档相关环境，明确提交为目标 | 应纳入文档事务；影响计算时标过期 | 校验失败不污染其他 store |
| 保存／导出 | 完整当前文档，显式命令 | 不使结果过期；保存成功才更新保存基准 | 保留文档并说明存储／文件错误 |
| 打开／导入 | 文档替换，验证后提交 | 清除无关旧结果；恢复完整文档的历史语义 | 失败保留原文档 |

## 4. 界面分工与菜单结构

### 4.1 工作区

当前保留主画布、顶栏计算与状态、结果面板、节点局部编辑器、完整设置页。新增搜索／网络详情采用按需面板的方案做原型，不预先把画布切成多个永久窗格。[R1][R3]

| 界面区域 | 负责 | 不负责 |
|---|---|---|
| 节点 | 资源与速率、少量高频编辑、局部状态 | 每行重复摆放低频策略按钮 |
| 配方编辑器 | 配比、耗时、范式、公用耗用、修饰器 | 网络目标和所有产线设置 |
| 供应与边界 | 当前机器的供给与运行／安装约束 | 改写配方定义或隐式增添供应节点 |
| 搜索／网络面板（规划） | 查找对象、成员列表、影响范围与定位 | 在浏览时悄悄改模型 |
| 结果与诊断 | 汇总、结果状态、问题定位及证据 | 自动修改条件来消除失败 |
| 设置页 | 本机偏好、产线规则、资源字典、单位环境 | 取代高频节点内联编辑 |

### 4.2 顶栏

顺序：**文件、编辑、选择、添加、整理、视图 → 计算与状态 → 设置、帮助**。

| 菜单 | 当前入口与规划归属 |
|---|---|
| 文件 | 打开、保存、导入、导出；新建、最近打开、另存为、示例、提取独立产线为占位 |
| 编辑 | 撤销／重做、剪切／复制／粘贴／副本、删除、删除节点、删除连线、补全端口、清空画布；批量策略为规划 |
| 选择 | 全选、取消选择、反选；全部／直接上下游、整条产线、两节点间链路、包含全局总线为占位 |
| 添加 | 配方、原料、目标、分流、自定义配方 |
| 整理 | 所选节点排布、六向对齐、水平／垂直等距、编组／重命名／取消分组均为占位 |
| 视图 | 适应视图、聚焦选中、100% 缩放、结果显隐；连线标签开关、统一问题定位为占位；节点显示（简洁／标准／详尽）为现有单选分组；搜索、返回原视野为规划；结果显隐仅控制详细面板，保留核心摘要 |
| 设置 | 直接进入完整设置页，不弹出“主题 · 浅色”等偏好列表 |
| 帮助 | 快捷键可用；指南、关于为占位 |

选择类操作已从“编辑”移至“选择”，快捷键保持不变。保留三种删除语义：删除全部选中项；只删选中节点及其关联连线；只删选中连线。只删节点时，保留不关联这些节点的其他选中连线。

菜单支持方向键、Home/End、Escape；未实现动作不绑定处理函数，也不启用虚假的快捷键。右键菜单为规划：只复用已有命令的上下文子集，不另造第二套选择／删除逻辑。功能增多后可分子菜单，不把不同状态拼成含糊的“某 · 某”动作名。

## 5. 节点视觉语言与容量

### 5.1 统一外观

纯色面板、12px 圆角、细边框、轻阴影；不使用渐变。所有界面图标使用共享 SVG，禁止 emoji 充当操作图标。原料保留青绿、目标保留橙色识别；颜色不作为唯一含义，保留文字、形状与无障碍名称。

配方标题为机器名；端点标题为“原料”“目标”，不重复增加“源”“汇”。配方左右为输入／输出，类别分组稳定：方向标题 13px 半粗，类别标题 10px，每类一个分隔，组内资源不逐行加线或重复类别名。

信息优先级为机器数量、最终产率，其次是连接关系与异常，最后是配方明细。原料端点数量左、名称右；目标端点名称左、数量右。标准／详尽模式的资源名与实际速率同行，简洁模式保留资源名与连接端口，隐藏中间工序的逐行速率。名称得到主要剩余宽度，数量列不无界扩宽。公用输入／输出保留语义分区，不为视觉整齐合并成普通配方 IO。

机器主数值突出安装需求，标准／详尽模式辅助显示精确运行量，例如“12 台 · 运行 11.4”；利用率不与主数值平分视觉权重。必须使用模型提供的对应语义，无法得到安装需求时明确标为运行量，不能把任意连续解取整后称为整数最优建厂方案。用户设置的机器上限与求解结果分别标识，保留就地修改入口，不让同一个无标签数字兼任设定与结果。目标节点各模式均突出实际产率与达标状态，设定量仍可就地编辑。

### 5.2 固定显示容量

| 区域 | 基线容量 | 超出处理 |
|---|---|---|
| 配方卡片 | 宽 420px，输入／输出各半 | 不随结果扩宽 |
| 配方标题 | 单行，操作区不压缩 | 省略并提供完整名称提示 |
| 配方资源行 | 简洁／标准 36px，详尽 50px；标准／详尽速率列 80px，简洁将其空间还给名称 | 单行省略；具体模式尺寸经原型验证后固定，不随数值改变 |
| 机器结果区 | 固定主数值槽；标准／详尽预留辅助运行量，详尽预留利用率 | 取消等宽三栏约定；空态同样占位，不因计算新增结果行 |
| 原料／目标 | 宽 320px；简洁原料行 46px，标准原料与简洁／标准目标行 70px，详尽行 84px | 内容结构不变时高度不变 |
| 端点数值 | 数值 70px、单位 42px；预留 12px 差额行 | 单位、差额可省略但完整值可查 |
| 分流器吞吐 | 单行 14px | 省略并提供完整值 |

资源增删、类别改变和用户主动展开结构可以改变高度。选中、悬停、语言切换及计算结果变化不触发自动撑高。长翻译允许省略或简短标签，并提供完整可访问名称。

极端容量处理（规划／试验）：三种模式默认均保留资源名和连接端口，减少数值不等于隐藏资源行。不设会截断端口的最大纵高，也不默认在节点内增加滚动区。单侧超过 8 条资源行作为原型测试样例，不作为自动折叠阈值。按类别手动折叠是独立试验，不由显示模式自动触发；类别摘要保留方向、资源数量、异常数量与结果状态。已有连线的端口必须保留可辨识锚点和资源身份，不能将不同网络压成一个可连接端口；若无法满足，保持资源行展开。展开／收起由用户触发，不因计算或选中自动变化。

详尽模式中的多修饰器使用固定单行摘要与“更多 N 项”详情入口，完整列表和执行顺序仍在编辑器中查看；计算不自动增加标签行，其他模式不常驻修饰器参数。极端用例至少覆盖单机 5 种修饰器、十余种副产物、双侧多类别和长翻译，验证连接辨识与键盘操作后再确定容量参数。

### 5.3 状态与动作分离

配方标题栏保留已建、补全、供应与边界、编辑入口；供应配置不放在每条输入行。显式外供显示紧凑状态标记，有限外供提示包含按显示单位换算的上限。无线图标只表示全局总线，沿用 v1 圆点加两道弧线、左右镜像的图案。

没有物理线不能直接判为缺料；共享网络可能由别处供给。警示必须来自编译或诊断证据。现有外供标记是查看状态，不伪装成可点击按钮；键盘可获得等价信息，提示不能仅依赖鼠标悬停。

## 6. 配方、端点和单位编辑

### 6.1 配方编辑

固定四宫格：左侧输入／输出，右侧机器／修饰器；上下两行等高，各区内部滚动。窄窗口切为有明确区高的纵向布局，不让长表把保存按钮推到无法到达的位置。

保留类别、资源 ID、单位、数量、计量基准、概率、全局、实际速率等字段的语义分工。ID 列优先获得宽度；类别列紧凑；实际速率有独立数值样式，不与原始用量混淆。删除沿用淡红底、细红边、浅红叉号，不用高饱和实心红块。

修饰器是独立模块与独立编辑区。执行顺序影响计算，不按字母或显示名自动排序；默认／必需修饰器保持锁定语义。条件不兼容时给出原因，保存前检查，不在后台静默移除参数。

### 6.2 内联提交与选择控件

数量编辑：Enter 提交，失焦提交有效草稿，Escape 放弃本次草稿。空值、负值或无效数值不能被悄悄写入模型；字段错误贴近字段显示，保留用户输入供修正。

所有下拉控件复用主题化可搜索 Combobox：候选、选中、焦点和禁用样式一致。资源 ID 可自由输入；类别、单位、范式与目标模式仅接受有效候选。上下键导航、Enter 确认、Escape 关闭并取消搜索；弹层不被表格裁切。只有两种明确偏好的主题／语言可使用设置页里的直接选择按钮，不强制包成下拉。

### 6.3 端点与分流

同一端点内多条资源保留各自数量。共同模式切换是一次操作，不能将所有数量覆盖为同一值；混合模式显示“混合”。有容量／状态端口时禁用不适用的普通共同模式，并保留完整设置入口。

有限模式直接编辑设定值；无限、最大化等模式展示实际值或“—”。差额仅在有证据时显示，设定与实际可分别查看。

分流器左右展示输入资源与输出比例。比例整组编辑、合计校验为 100%；保存整组、取消恢复、一撤销恢复整组。分支增删、容量和资源保留完整设置入口。

### 6.4 单位语义

显示单位与计算单位分离，内部保持精度，显示阶段格式化。改显示单位要维持同一物理量；TPS 属于计算环境，不能视为纯主题偏好。概率为零或不消耗的端口保留库存／启动用途，不要求普通正流量供应线。

## 7. 输入供应、网络与目标

### 7.1 局部建模

“不关心来源”不等于“不消耗资源”。用户可以不画来源节点，而在“供应与边界”显式开启外供。空上限表示充足供应，有限上限按显示单位编辑。外供附着于实际共享网络，可能补给同网络的其他机器；不同独立网络即便资源同名也不能互借。

批量“未连线输入设为供应充足”只处理当前范围内未连接、未设边界的普通正流量输入；现有即便无效但仍存在的连线也按已连接保守跳过，不用外供绕过连线错误；不改已有有限上限、全局总线、库存、容量、工况。必须显示本次范围，不能因一个局部入口偷偷处理整份文档。

“补全端口”生成可见节点和连线；外供是另一种建模方式。已有外供或明确出口时，补全不能添加无限来源／出口绕过条件。取消外供恢复由连接网络供料，无来源时给出真实诊断。

### 7.2 端点模式

| UI 含义 | 领域语义 | 必须避免的误读 |
|---|---|---|
| 无限供应 | source，capacity=null | 不是实际消耗无限 |
| 限量供应 | source，capacity=上限 | 不把显示单位数直接当标准单位 |
| 需求量／至少生产 | delivery，at_least | 不偷偷变成精确等式 |
| 固定产量 | delivery，exact | 与最低需求分开 |
| 最大化 | delivery，maximize | 缺乏上限可能无界，不能伪造有限答案 |
| 接收剩余产物 | delivery，export | 与排放分开 |
| 溢出排放 | spill | 不是 exact 0，不算交付 |

### 7.3 有线／全局切换

在资源编辑的“全局”列切换。主动改为全局并保存时，说明并断开该端口已有物理线；一次撤销恢复端口策略与连线。切回有线不猜连接目标。锁定端口禁用并说明原因；导入旧问题图或修改无关字段时不自动删线。

## 8. 搜索、选择与网络查看（规划／占位）

### 8.1 三种状态不混用

- **选择**决定编辑、删除、复制等动作作用对象。
- **高亮**只强调关系，不改变当前选择集，不使删除范围扩大。
- **聚焦**改变视野，不改模型；计划提供“返回上个视野”。

搜索按节点名、资源显示名和 ID 检索，结果附对象类型与所在节点／工段以区分重名。输入即时过滤列表，选中结果后才居中；不随每个字符移动画布。空结果、清除搜索和返回原视野有明确路径。默认搜索整份产线，局部范围需显式选择。[R1][R3]

### 8.2 关联选择契约

| 操作 | 目标行为 |
|---|---|
| 直接上游／下游 | 起始集合加一层相邻节点和相应连线 |
| 全部上游／下游 | 沿指定方向递归取并集，包含起始节点；循环访问去重 |
| 整条产线 | 忽略方向，选取起始节点所在连通部分的并集 |
| 两节点间链路 | 显式确定起点和终点；选取属于起点到终点有向路径的节点与边，不只最短路径；没有路径则保留原选择并提示 |
| 包含全局总线 | 显式开启的追踪选项，默认关闭；以实际网络身份扩展，不能按同名字符串连接 |

默认基于可见连线，选择结果替换原集合；多起点取并集。跨工段不默认截断，隐藏在组内的匹配项要有数量提示。大范围选择先显示数量与范围，不能无声选择不可见的大量节点。上述规则是待验证契约，不宣称当前菜单已能执行。

### 8.3 实际共享网络

“查看资源网络”从具体端口进入，按当前文档的网络身份列成员、供给／需求边界、全局范围，联动画布高亮。与“默认按可见连线选择上下游”明确区分；无需先点击“计算”，也不依赖后端在线。

实现边界（规划）：当前 `networkCompiler.ts` 的完整模型编译发生在前端，后端接收模型并求解。即时网络查看应从现有编译流程提取、复用纯拓扑解析规则，而非另写一套近似合网逻辑或依赖旧 `topology.ts` 的名称规则。物理网络依据有效端口与通过连接校验的可见连线；全局网络仅对全局路由端口按 `scopeId + resourceId + busId`（包含规范默认值）识别，不能只按 busId 或资源名合并。使用当前配方与修饰器解析后的端口，保留稳定端口身份。

拓扑解析允许报告局部错误，不以目标、外供是否齐全或 LP 是否可行为前提。缺失端口、非法连线和无法解析的配方单独标记，不将其猜测为有效连接；仍可展示其他可确认成员。单位／数学语义冲突须标为网络配置错误，不能因为拓扑可追踪就显示“可计算”。完整编译继续负责求解模型约束校验，求解器负责可行性与数值结果；三者的状态分别表达。编辑后按文档版本更新高亮，旧版本异步结果不得覆盖新拓扑。

多个网络使用同一资源时分别列出；不根据名称合并。当前图尚不能可靠编译时，展示可确认的连接及诊断，明确网络信息不完整，不用旧网络结果冒充当前网络。高亮是连接关系解释，不是瓶颈或因果证明。[R3][R8]

## 9. 批量操作与可逆编辑（规划／待完善）

### 9.1 共同交互

框选或搜索建立选择集 → 选择批量动作 → 显示适用对象、跳过对象与原因 → 设置公共参数 → 提交一次 → 简短反馈 → 一次撤销。

显示“对 8 个目标端点设为溢出排放”，而不是含糊的“应用到全部”。混合值显示“混合”，不显示第一个对象值假装共同值。默认只修改用户明确编辑的字段，保留其他数量、单位和规则。禁止在选择过程中自动提交。

预检查区分不适用对象与实际错误：不适用项可明确跳过；适用集合提交过程中遇到验证失败，应整体不提交并定位错误，不能静默半成功。影响范围涉及共享网络时也要展示超出所选节点的网络影响。[R7]

### 9.2 各动作边界

| 动作 | 范围与保护 |
|---|---|
| 批量外供 | 选中配方中的合格未连输入；沿用第 7 节排除条件 |
| 批量端点模式 | 仅适用的原料或目标端点；spill 只应用目标；保留各资源原数量，不修改配方定义 |
| 批量修饰器 | 检查范式、必需修饰器、参数和执行顺序；首版对已存在同类规则默认跳过并说明，不暗中覆盖或重复挂载 |
| 批量补全 | 沿用已有边界保护，整批新增节点、连线与配置一起撤销 |
| 批量布局 | 仅修改呈现结构，不使计算结果过期；显示模式首版统一作用于全画布 |

“补全所选配方”已先计算整批变更，再一次提交和快照；失败不留下前面节点的部分修改，一次撤销恢复整批。规划编辑器的外供批量按钮不等于完整多选批量体系。

### 9.3 历史与保存

按用户意图组织事务：一次模式切换、拖拽结束、整组比例保存、批量操作各是一条历史，不按底层字段或鼠标事件拆分。撤销同时恢复图、配方、边界和相关环境；撤销后发生新的文档编辑必须清除 redo 分支。选择／定位／过滤不污染文档撤销栈。

只读展示操作与文档状态分开；“已建”不触发重算，但仍属于应保存、可撤销的文档信息。未来命令可共用适用判断、执行与撤销；不为入口方便复制业务逻辑。

## 10. 工段、显示模式与整理

### 10.1 分组先于折叠

第一阶段验证命名工段框、选中组与整体移动，保持内部端口可见。分组不改变计算网络，不规定必须 10–15 个节点。组边界表达用户组织意图，不自动按资源类别代替工段。[R6]

折叠另行设计：必须保留跨组连接与端口方向、资源身份，组摘要包含问题数量和结果状态；折叠不意味着停用内部计算。组名称相同不合并网络。展开恢复原内部布局，取消分组保留节点与连线。首轮不引入复杂嵌套组。

### 10.2 手动显示模式（现有）

统一采用“简洁／标准／详尽”，替代旧的“常规／紧凑”二分。模式只改变信息量，不启用额外计算能力。[R4][R5]

| 模式 | 默认节点信息 | 主要任务 |
|---|---|---|
| 简洁 | 机器名、主要机器数量、资源名与连接端口、异常标记；目标的实际产率与达标状态 | 大图概览、查看规模和产出 |
| 标准 | 简洁内容＋各资源实际速率、辅助运行数量、关键限制 | 建图、调量与配平 |
| 详尽 | 标准内容＋单机用量、利用率、概率、公用工程参数与修饰器摘要 | 排错与核对 |

完整编辑表单始终留在编辑器；任何模式均保留必要的就地编辑入口、供应／路由身份、异常和结果过期状态。简洁模式不隐藏连接所需资源行；公用工程的资源与端口始终可辨识，额外参数才按模式展示。

主入口为“视图 → 节点显示 → 简洁／标准／详尽”，单选并作用于整份画布。首次新建默认简洁；后续新建沿用本机最近明确选择。当前文档的模式随保存／导出保留，打开时优先恢复文档模式；旧文档无该字段时沿用本机偏好，无偏好则简洁。显示模式存于 v5 文档可选字段 `ui.nodeDisplayMode`（`compact`／`standard`／`detailed`），本机最近明确选择独立保存。它不进入计算版本、不使结果过期，纳入未保存状态判断，但不污染模型编辑撤销栈；打开文档不覆盖本机最近明确选择。

个别节点通过“查看详情”SVG 按钮打开原生模态详情浮层；Escape 关闭并返回入口焦点，不改变节点几何尺寸。关闭后仍遵循全局模式，不持久化为另一套节点模式。第一版不引入选区模式覆盖，避免全局切换后出现难以解释的混合状态。

手动切换模式允许高度变化，保持节点位置且不自动重排；各模式内部的尺寸固定，计算、选中、悬停和语言切换不自动扩展节点。切换后的重叠可由用户显式整理，不能偷偷挪动节点；验收需关注重叠程度及端口可操作性。最终产率摘要不随节点模式隐藏。

缩放自动改变信息量属于单独试验，不作为首版默认。若测试语义缩放，优先只改变文字细节，不改变节点几何尺寸；避免缩放阈值附近反复跳动。

### 10.3 整理

整理所选节点、对齐、等距都由用户触发，未选中区域位置保持。对齐使用节点外框，等距计算考虑实际尺寸，避免以中心等距造成大节点覆盖。布局仅改变位置，不改连线语义、边界或节点执行状态；一次撤销恢复。

自动排布需处理循环、跨组连接与固定节点，先提供局部结果预览或可立即撤销的应用方式。绝不在重算后自动全图重排。布局质量与稳定性需要任务实验，不以交叉线数量单一指标替代。[R4]

### 10.4 提取独立产线

文件菜单仅占位。规划流程：选择子图 → 预览跨边界的资源网络 → 明确新增外供／目标／排放策略 → 生成新文档或导出，原文档不改。

不能将每条跨界线直接复制为独立无限来源：共享网络可能跨越多个所选端口；有限供给、容量、状态和概率／库存约束也不能丢失。按网络身份去重并要求确认边界含义；保留配方、修饰器、单位环境与必要注册表。不能忠实表达的约束阻止提取并说明，不静默弱化为无约束模型。

跨界双向耦合：若同一跨界网络在选区中同时有消耗与产出端口，须单独提示可能存在回流／循环耦合；端口方向仅表明潜在交换，不能据此推断已发生的跨界流量。可让用户明确设置独立的“外部供给上限”和“固定／保底外部交付”，但这是新的边界假设，不保留原网络的回流比例或联合容量约束。不得从旧结果的净流量推算两侧毛流量，也不自动选择固定或保底模式。若用户要求保留原耦合，应扩大选区以包含相关工序，或等待可表达耦合约束的提取方案；当前无法表达时阻止该提取。预览与导出说明记录原网络、切断关系及新假设，不将其标为等价复制。

## 11. 结果、计算状态与诊断

### 11.1 结果生命周期

| 事件／状态 | 界面行为 |
|---|---|
| 从未成功计算 | 显示“未计算”和“—”，不伪装为零 |
| 成功／已验证可行 | 展示对应求解状态，区分可行解与已验证最优 |
| 修改计算条件 | 保留结果，显示“产线已修改，点击计算更新结果” |
| 正在计算 | 保留旧结果并显示计算中，不允许旧请求覆盖新文档 |
| 不可行、无界、超时、服务失败 | 保留上次有效结果，同时明确本次状态；无旧结果则保持空态 |
| 新结果通过验证并被接受 | 一次更新对应结果，包括预算内得到的已验证可行方案；不混合两个版本的节点投影 |
| 打开另一文档、导入、明确清空 | 清除不再属于该文档的结果 |

保留的是上次已验证的数值结果，修改条件或开始新计算时旧诊断／瓶颈分析可能已被清除，不能继续当成当前证据。没有新最优解但存在已验证可行方案时可以接受新结果，并清楚标为可行而非最优。

结果应可辨认其对应的条件版本；完整版本／时间查看为规划。语言、主题、选择、位置、结果显隐及已建标记不使求解结果过期。显隐面板不等于删除结果。[R2][R8]

### 11.2 汇总和长列表

分别展示外部输入、交付、排放、设备需求和启动占用。运行量、整数安装、已有设备、新增设备不混称。默认先展示影响决策的摘要，明细按需展开。

在顶栏下、画布坐标区外的固定 60px 区域持续显示最终产品实际产率、安装机器总数和计算状态，不要求平移画布寻找目标；详细结果面板可收起，但这份核心摘要在三种节点模式下均保留。产率按明确交付目标及资源身份汇总，不能把中间产出或溢出排放当作最终产品，也不能重复累计同一交付结果。不同资源／量纲不相加为一个总产率；多目标按稳定顺序展示，前两项常驻，更多项通过带数量的入口展开，明细内部滚动，不撑高摘要。无明确交付目标时显示“未设置交付目标”，不猜测末端节点就是产品。机器总数使用安装需求并可展开类型明细，不混入已有／新增或运行量；尚无有效结果显示“—”。旧结果保留时摘要同时显示过期状态，不能暗示当前目标已经达标。

规划所有长列表提供即时过滤、匹配数量与清除入口，保留滚动和搜索上下文。搜索数据范围是完整列表，不只是已经渲染的一屏；计算更新后不丢当前过滤条件。

| 列表 | 建议筛选 | 排序约定 |
|---|---|---|
| 资源字典 | ID、显示名、类别、已使用 | 名称、类别；使用次数需有真实统计后提供 |
| 产线设置 | 节点、资源、边界类型、配置状态 | 默认稳定节点顺序；按问题／状态筛查 |
| 结果汇总 | 资源、类别、交付／排放、缺口 | 同可比较量纲先换算统一单位再比较；库存量与流量分开 |

不同量纲不能直接按原始数值混排；不足与不可比较数据要有明确状态。用户编辑字段期间不自动重新排序导致行跳走。列表优化如虚拟滚动应保持焦点和键盘操作，不能只验证帧率。[B1][R5]

### 11.3 问题解释

诊断依次给出：**发生什么 → 涉及哪个目标／资源／节点 → 有什么证据 → 可检查哪些条件 → 定位入口**。定位只改变视野与高亮，不自动删除或放宽约束。

- 缺来源、缺去向、有限供给不足、产能不足、无界与服务故障分别命名。
- 不可行解释不是随意猜出的“瓶颈”；仅展示求解器／编译器能证明的范围与证据，候选原因标为待检查。
- 旧结果与本次失败并存时，面板明确“上次结果／本次诊断”。
- 隐藏或折叠诊断面板不隐藏总体失败状态；多个问题提供筛选与逐项定位的规划入口。
- 昂贵解释可延后展开；目标交互应允许取消分析、重试并保留已有信息（当前没有独立取消按钮，不能把内部请求废弃机制当成已交付取消交互）；不承诺即时完成所有分析。[R8]

## 12. 完整设置页与草稿

顶栏“设置”进入完整页面：左侧分类、右侧内容、明确返回画布。页面打开期间画布快捷键不响应；不通过平铺下拉切换“某 · 某”选项。

| 分区 | 数据归属 | 提交方式 |
|---|---|---|
| 常规与外观：主题、语言 | 本机 UI 偏好 | 即时生效，不进入产线文档、不影响计算 |
| 产线与网络 | 当前文档约束 | 草稿编辑，保存设置后应用；保存后留在页面 |
| 资源字典 | 当前文档相关注册表快照 | 草稿编辑，应用；不凭“全局”二字暗示云端跨文档同步 |
| 单位与 TPS | 当前计算环境 | TPS 有效失焦／Enter 提交，Escape 放弃字段草稿；一次提交一次撤销 |

切换分区保留草稿，不自动应用。重置更改恢复当前已提交值。保存设置／应用字典只修改内存中的当前文档，不等于已完成文件菜单保存或导出。

返回画布或 Escape 时，存在未应用草稿才提示放弃确认；取消保留页面与草稿，普通浏览直接返回。TPS 在有效失焦或 Enter 时作为一次文档编辑提交，Escape 放弃当前字段草稿。关闭浏览器也对未应用草稿提供保护；各分区独立提交，不自动保存其他草稿。

搜索结果将来可直接定位设置分区与对象，但仍复用同一编辑器与提交语义。设置页不常驻冗长教学文字；只在会影响物理含义、范围或数据保存的地方给简短必要信息。

### 12.1 供应、机器与网络编辑布局

单机设置与供应／目标节点设置复用同一套边界、数量及单位字段。单机按“机器数量 → 输入供应 → 输出与排放”排列；网络与资源属性、优化参数折叠展示。非普通流量输入另列“其他输入条件”，不能因简化布局而隐藏容量或状态端口。

资源按类别分组，每个类别仅一个分隔标题。资源名保留主要宽度，数值框保持短宽，显示单位紧随数值；取消逐资源大卡片。外供勾选用于日常操作，其他外部连接方式仍可展开编辑。目标设置同时包含交付和排放，不能用“需求”概括排放条件。

全局“产线与网络”分为机器、供应与交付、网络与资源属性、优化四个分区。即时搜索匹配节点名／ID、资源名／ID及类别，显示匹配数量并可清除。搜索和分区切换只影响展示，保留同一份草稿；分类内保持端口顺序，不因数值编辑自动重排。资源行标明所属节点与列表序号，节点 ID 可通过提示查看；同名资源不合并为同一网络。

“外供当前列表中的未连线输入”只作用于过滤后可见输入，继续遵循第 7 节的排除规则。全局机器优化仅在全局优化分区编辑，避免单机弹窗暗中修改整条产线目标。过期配置清理也只在全局网络分区提供。

底部固定操作区：弹窗为取消／应用，全局页面为重置更改／应用；显示未应用或已应用状态。应用仍沿用既有配置校验、显示单位换算和一次快照提交，不修改计算模型、端口身份或求解过程，不代替文件菜单保存。

## 13. 文档、剪贴板与首次打开

### 13.1 保存与导入

现有“保存”保存至浏览器本地存储，“打开”读取该本地保存；“导入／导出”处理 JSON 文件。不要将现有菜单文案解读为已支持文件系统另存为、项目列表或云同步。新建、最近打开、另存为、示例选择仍是占位。

文档保存基准包含图、权威配方、网络配置、单位环境和资源字典；本机保存成功或成功打开文档才更新基准。计算结果与选中状态不计入未保存状态；撤销回到保存内容会恢复干净状态。菜单显示“未保存”，浏览器关闭、打开／导入替换和清空对未保存内容提供保护。导出下载无法确认实际落盘，因此不清除本机保存状态。

导入先验证和迁移，再原子替换文档。失败保留原图；迁移警告可查看，不把损坏结构静默删除。导出不伪装包含可复用的最新计算结果。将来增加工段与折叠状态时，明确哪些随文档保存、哪些只是本机会话状态。

### 13.2 剪贴板与复制

复制／副本保留子图内部语义，重新生成身份，避免与原网络意外串接。跨选区连接不自动补成无限供给；提取独立产线使用第 10.4 节的专门流程。

粘贴优先读取系统剪贴板；API 不可用或读取失败才回退内部缓存。成功读到空文本、无效 JSON 或非画布内容时提示错误，不悄悄粘贴旧缓存。

### 13.3 初次体验

保留当前钢锭 10 个/min 示例：粉碎机、电解机、电力高炉，两个无限原料、一个需求与两个副产物排放节点。主流程在上、制氧支线在下；电力显式外供，高炉 MV，安装量自动规划。示例单位环境随文档保存，不改全应用隐式默认。

初始化通过正常入口请求一次计算，不预填答案；后端不可用时保留模型并显示真实问题。以后提供空白／示例选择时，不覆盖已保存工作，也不把演示结果当成用户当前数据。

## 14. 键盘、焦点、多语言与响应式

现有 Ctrl/Cmd+A 全选，C/X/V 剪贴板，D 副本，Z 撤销，Shift+Z 或 Y 重做；Delete/Backspace 删除选中。文本输入、可编辑元素、菜单、设置和弹窗优先处理按键，禁止后台画布误删。

Escape 按最内层处理：候选列表／当前草稿 → 弹窗或页面的关闭规则 → 临时高亮 → 画布取消选择。搜索／高亮等规划功能不得抢占浏览器或输入框原有快捷键；新增快捷键须先确定冲突和帮助文案，不能只在菜单展示。

弹窗包含清晰标题、提交与取消，焦点应限制在当前层，关闭返回触发入口。节点按钮和输入不触发拖动；焦点移动不滚动画布外层。状态不只靠颜色，所有 SVG 操作按钮有可访问名称，长内容除悬停外也可通过键盘或详情读取。当前未完成全套屏幕阅读器与跨浏览器验收。

所有 UI 文案用 `src/common/i18n` 类型化键值词典；新增键同时提供中英文，插值传参，配置存键而非中文反查。主题／语言只存本机偏好。用户名称、资源 ID、单位符号和协议枚举不因换语言被改写；内置类别／范式在显示层翻译，资源名遵守 v2 §11.2 回退契约。

计算核心保持语言无关；已知诊断在显示边界翻译，未知插件／后端信息原样保留。长期使用稳定错误码与参数替代历史文本匹配，当前未完成。英文长标签、中文名称和数值都须验证固定节点容量。

宽屏保留既有布局；窄屏设置分类可横向滚动，编辑器分区重排但操作仍可达。此设计不等于承诺完整手机触控建图；触控连接、缩放与悬停替代需单独测试。

## 15. 实施前的验证计划

研究模型 [R2] 要求分别验证：领域语义是否正确、用户任务是否合适、交互是否有效、算法与渲染是否足够快。用真实的小／中／大型文件，例如约 10／40／100 节点并变化连接密度；这些只是测试样例，不是论文给出的产品阈值。

| 对照任务 | 最小原型比较 | 记录指标／通过条件 |
|---|---|---|
| 调需求与回退 | v1 常用流程／当前版／候选入口 | 耗时、点击、错误；不得丢单位、条件或恢复能力 |
| 理解共享网络 | 现有标记 vs 网络高亮与成员列表 | 正确判断哪些机器得到外供；不能将同名独立网络误认为连通 |
| 批量修改混合节点 | 逐一修改 vs 有范围说明的批量动作 | 漏改、误改、跳过原因理解；一次撤销完整恢复 |
| 找上游和返回 | 手动缩放 vs 搜索／追踪／返回视野 | 定位正确率、迷路次数、视野恢复 |
| 阅读多工段 | 原图 vs 命名组框；显示模式单独测试 | 跨组依赖辨识、目标理解；不要同时引入三项变化掩盖原因 |
| 机器数量与最终产率 | 同一产线分别使用简洁／标准／详尽，包含几十台机器的真实文件 | 找到设备需求与交付产率的时间、误读率、详情打开次数；简洁态仍能连线和调量 |
| 显示模式稳定性 | 三种模式切换、重算、打开旧／新文档、多目标和长翻译 | 模式恢复正确；计算不改变尺寸；切换不移动节点；端口可用；摘要不混淆旧结果、不同量纲与排放 |
| 求解失败与旧结果 | 当前状态 vs 更明确的结果归属／诊断 | 不把旧结果当新结果；能指出下一步检查条件 |
| 设置与文件保存 | 即时偏好／草稿／保存文档三种流程 | 能区分生效、已应用、已持久保存；离开不意外丢草稿 |
| 双语与可访问性 | 长名／长翻译／键盘／宽窄窗口 | 不遮挡、无后台误操作，关键动作可到达 |

先用纸稿或可点击原型走查，再实现最小功能。邀请熟悉原工作流的用户与初次使用者分别观察；记录参与者、任务、数据和失败案例，不把少数人的意见写成统计显著结论。先设定比较指标，再收集结果，不事后挑选支持方案的截图。

## 16. 推荐推进顺序与暂缓项

1. **先补可靠性基础**：文档事务、redo 清理、草稿离开规则、保存基准和剪贴板来源。没有这些基础，批量操作会放大损失。
2. **验证查找与理解**：画布搜索、实际网络高亮、上游追踪、返回视野；实现前验证可见图和共享网络的区分。
3. **验证低歧义批量动作**：未连线外供、目标端点模式、批量补全的一次撤销；再研究混合修饰器。
4. **逐步改善大图**：优先验证三种显示模式及固定产率摘要，再推进命名分组与局部整理；类别折叠与语义缩放分别做试验。
5. **完善解释与提取**：有证据的诊断、长列表联动，最后才开启边界语义复杂的独立产线提取。

不默认自动选中即展开、重算后重排、同名资源自动合网、隐藏跨组端口、将所有数量编辑搬到设置页，也不因某论文使用矩阵或选择性撤销就引入高成本机制。菜单占位不决定开发先后，实验失败可以修改或撤回规划。

### 18.3 每次变更的记录要求

记录原入口与新入口、改变原因、关联任务、研究依据及其局限、实现状态、验证结果和遗留风险。新增规划先修改对应章节和第 17 节，不继续在文末追加互相冲突的临时规则。新功能启用前移除相应“暂不可用”必须以真实能力与验收为依据。

显示模式实现复用既有供应与边界编辑器、文档事务及单位体系；单机运行上限继续就地修改。标准／详尽的实际结果缺失时显示“—”，单机参数仅在详尽或详情中展示；容量／状态不使用流量单位。三种模式未引入分组、自动排布、语义缩放、网络追踪或通用批量编辑。
