# 参与贡献 OmniFlow

[English](../CONTRIBUTING.md) | 中文

请先阅读 [Repository Guidelines](../AGENTS.md)。实现策略、架构边界、开发命令、代码风格、验证和 PR 要求统一维护在该文件中，适用于贡献者和 coding agent；本页不再维护另一套规则。

## 贡献流程

1. 明确问题并检查已有 issue；按需 fork 仓库，在独立分支上完成聚焦的修改。
2. 遵循 `AGENTS.md` 中的实现策略，使改造范围与问题规模相称。
3. 执行与变更相关的检查，记录真实结果。
4. 提交 PR，说明改动后的行为、关联 issue 和迁移要求。UI 修改附截图，计算逻辑修改提供可复现案例。
