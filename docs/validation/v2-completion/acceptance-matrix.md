# v2 T01–T24 acceptance evidence

This matrix maps the design scenarios to executable evidence present on 2026-10-23. It distinguishes schema/domain tests, actual SciPy solves, HTTP tests and browser observations. A module or passing type check is not itself acceptance evidence. PR numbers refer to local implementation stages; no remote PR is implied.

The final integrated run reported by the coordinating agent verified 212 frontend tests in 22 files and 163 backend tests with no skips, ESLint without warnings and a successful production build (approximately 677 kB main-bundle warning). This includes PR-08 installation, actual installation-response projections and splitter-diagnostic follow-up tests. Exact commands, final release status and browser screenshots are owned by the [continuation ledger](README.md). The four historical skipped HTTP mathematical cases are now active LP tests. This document does not reuse the pre-v2 test counts as evidence for new behavior.

## Release interpretation

The existence of a test entry above establishes only its stated layer. The previously identified T07/T08/T10/T18 quantitative integration gaps have corresponding real compiler/solver cases now. Unobserved browser paths remain unobserved, rather than being inferred from fixtures. The root continuation ledger owns final release status, screenshots and browser performance. Dynamic startup proof, integer installation optimization, forced native termination and unvalidated marginal expansion benefit are deliberately outside the implemented guarantees.

Backend performance evidence is in [performance-backend.md](performance-backend.md): fixed hardware, raw samples, size/nonzero/layer/span statistics, serialization/loopback/queue/solver P50/P95 and native process peak memory. It expressly does not claim frontend compile or render measurements.
