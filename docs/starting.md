# Windows 一键启动

双击项目根目录的 **`start.bat`**。首次运行需要已安装 Node.js（20.19+、22.12+ 或更高受支持版本）和 Python 3.11+，并联网下载依赖；已有依赖时直接启动。

脚本会检查环境，按需安装前端依赖、创建 `.venv` 并安装锁定的后端运行依赖。随后启动前端和后端，等两者就绪后自动打开 **http://127.0.0.1:5173**。

保留启动窗口；按 **回车** 或 **Ctrl+C** 停止本次启动的两个服务。后端代码修改后需要重新启动脚本。日志保存在 `logs/start-日期时间/`，该目录不会进入 Git。

端口已被占用时会给出提示，不会关闭已有进程。先关闭原来的服务再启动，或在 PowerShell 中使用其他端口：

```powershell
.\start.bat -FrontendPort 5174 -BackendPort 7999
```

其他可选参数：

```powershell
.\start.bat -NoBrowser  # 启动服务，但不打开浏览器
.\start.bat -CheckOnly  # 只检查环境，不安装依赖或启动服务
```

脚本从自身所在目录定位项目，可以从其他目录调用，也支持带空格或中文的项目路径。启动时仅为子进程设置 `VITE_BACKEND_URL`，使前端连接本次启动的本地后端，不修改已有 `.env` 文件。前端直接调用本地 Vite，安装依赖时调用 Node.js 自带的 npm CLI，不依赖 PowerShell 的 npm 快捷入口。

## 验证记录

2026-10-23 在 Windows PowerShell 5.1 下验证：从项目外调用 `start.bat -CheckOnly`；使用 15173/17998 端口实际启动，检查后端接口和前端的后端地址；重复启动时拒绝端口冲突并保留原服务；回车、Ctrl+C 均停止本次启动的服务并释放两个端口。脚本语法检查通过。

首次缺少依赖时的联网安装分支尚未在空环境中实测；现有环境的依赖版本检查通过。自动打开默认浏览器使用系统关联，启动验证时使用 `-NoBrowser`。
