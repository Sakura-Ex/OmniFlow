# Contributing to OmniFlow

English | [中文](docs/CONTRIBUTING.zh-CN.md)

Read [Repository Guidelines](AGENTS.md) for the shared implementation strategy, architecture, setup commands, coding conventions, validation, and pull request requirements. Those rules apply to contributors and coding agents; this page does not maintain a second copy.

## Contribution Workflow

1. Identify the problem and check existing issues. Fork the repository if needed and work on a focused branch.
2. Follow the implementation strategy in `AGENTS.md`; keep changes proportional to the problem.
3. Run the checks relevant to your change and record their results.
4. Submit a PR explaining the resulting behavior, linked issues, and any migration requirements. Include screenshots for UI changes and reproducible cases for calculation changes.
